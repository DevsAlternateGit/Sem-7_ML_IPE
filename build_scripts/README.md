# Notebook Generator Scripts

Run these scripts from the project root or from within this directory to regenerate the exam notebooks:

1. `python build_scripts/build_nb01.py` - Generates 01_decision_trees.ipynb (Q1 to Q4)
2. `python build_scripts/build_notebooks.py` - Generates 02_cross_validation.ipynb (Q5) 03_naive_bayes.ipynb (Q6), 04_svm.ipynb (Q7 to Q9), and 05_regression.ipynb (Q10 to Q11)
3. `python build_scripts/build_nb06.py` - Generates 06_kmeans_elbow.ipynb (Q12 to Q14)
4. `python build_scripts/build_nb07.py` - Generates 07_dbscan.ipynb (Q15 to Q16)
5. `python build_scripts/build_nb08.py` - Generates 08_pca.ipynb (Q17 to Q21)
6. `python build_scripts/build_nb09.py` - Generates 09_lda.ipynb (Q22 to Q25)
7. `python build_scripts/build_master.py` - Generates 00_master_revision.ipynb (Master Guide)
